# 🚲 دراجة الأبطال: مغامرة الانسحاب والانعكاس

لعبة تعليمية تفاعلية ثلاثية الأبعاد بأسلوب الأنيمي لدرس **٢-٦ الانسحاب والانعكاس** (رياضيات الصف الخامس).
البطل (ريان أو ليان) يقود دراجة هوائية عبر ثلاث مراحل مليئة بالتحديات، ويحصل في النهاية على **كأس البطل الذهبي** مع تقرير بمستوى إتقانه لكل مهارة.

## طريقة التشغيل
- افتح الملف `index.html` في أي متصفح حديث (Chrome / Safari / Edge / Firefox) على الهاتف أو اللوحي أو الحاسوب.
- أو شغّل خادماً محلياً بسيطاً: `python3 -m http.server` ثم افتح `http://localhost:8000`.
- يمكن نشرها مجاناً عبر **GitHub Pages** (Settings ← Pages ← Branch) ليفتحها الطلاب برابط مباشر.
- لا تحتاج اللعبة إلى إنترنت: مكتبة Three.js وخط Cairo مضمّنان في المجلدين `lib` و`fonts`، والأصوات مولّدة برمجياً.

## المراحل
| المرحلة | الفكرة | التحكم |
|---|---|---|
| ١. الاختيار دون توقف | أسئلة جوية تظهر أثناء القيادة، والإجابات موزعة على ٣ مسارات ملوّنة؛ يختار اللاعب المسار الصحيح قبل البوابة | تغيير المسار يميناً/يساراً |
| ٢. محطات التحدي | توقف عند ٦ محطات؛ الإجابة الصحيحة ⚡ انطلاقة سريعة، والخطأ 🐢 تباطؤ مع تفسير مبسّط | اختيار الإجابة أو التلوين على الشبكة |
| ٣. منعطفات الأبطال | طريق جبلي متعرّج فيه نجوم وحواجز وقوة طرد في المنعطفات، وينتهي بـ **سؤال الأذكياء ٢** الذي يجمع الانسحاب والانعكاس | توجيه مستمر |

**التحكم:** الأسهم ← → أو A / D على الحاسوب، وأزرار التوجيه أو اللمس/السحب على الشاشة في الهاتف واللوحي. المسافة أو Esc للإيقاف المؤقت.

## المحتوى التعليمي
- **أنواع الأسئلة:** تحديد العنصر، إكمال العمل (ومنها التلوين على شبكة المربعات)، الاختيار من متعدد، التصويب.
- **المهارات المقيسة:** مفهوم الانسحاب، وصف الانسحاب (المسافة والاتجاه)، مفهوم الانعكاس وخط المرآة، رسم الانعكاس والبُعد عن خط المرآة، الأنماط والتمييز بين التحويلين.
- **التدرّج:** أسئلة مفاهيمية سهلة ← وصف ورسم ← سؤال مركّب متقدم. كثير من الأسئلة يُولَّد عشوائياً (أشكال ومسافات واتجاهات مختلفة)، فتختلف كل جولة عن سابقتها.
- **تغذية راجعة فورية** مع تفسير بعد كل إجابة، وتلميح اختياري في أسئلة الرسم.
- **النتيجة النهائية:** النقاط، النجوم، الوقت، الدقة، شارات الإنجاز، ونسبة الإتقان لكل مهارة (متقن / جيد / يحتاج تدريباً).

## بنية الملفات
```
index.html          الواجهة (عربية بالكامل، RTL)
css/style.css       التصميم المتجاوب
js/questions.js     بنك الأسئلة ومولّداتها
js/figures.js       رسم الأشكال على شبكة المربعات
js/hero.js          البطل الأنيمي والدراجة (تظليل كرتوني، تعابير وجه، حركة دوّاسات)
js/world.js         الطرق والبيئات والبوابات والمحطات والعقبات والكأس
js/audio.js         المؤثرات الصوتية والموسيقى (Web Audio)
js/main.js          منطق اللعبة والكاميرا والتحكم والنتائج
```

لإضافة أسئلة جديدة عدّل `js/questions.js` (كل سؤال: نص، خيارات، رقم الإجابة الصحيحة، المهارة، التفسير، ورسم اختياري).
