# 🏰 مغامرة إنقاذ مملكة الحروف

لعبة تعليمية تفاعلية لتعليم الحروف الهجائية العربية الـ٢٨ لطلبة **الصف الأول الأساسي**.
هبّت «عاصفة النسيان» فبعثرت الحروف في سبعة عوالم، ومهمة الطالب وبطله — بمساعدة **حكيم الحروف** — استعادتها حرفاً حرفاً.

## التشغيل
- افتح `letters/index.html` في متصفح حديث (Chrome / Edge / Safari / Firefox) على الحاسوب أو اللوحي أو الهاتف.
- أو شغّل خادماً محلياً: `python3 -m http.server` ثم افتح `http://localhost:8000/letters/`.
- يمكن نشرها عبر **GitHub Pages** ليفتحها الطلبة برابط مباشر.
- تعمل **دون إنترنت**: مكتبة Three.js وخط Cairo مضمّنان، والمؤثرات الصوتية مولّدة برمجياً.
- **لوحة المعلم:** زر «لوحة المعلم» في الشاشة الأولى، أو افتح `letters/teacher.html`.

## مسار الطالب
1. اختيار الاسم أو إنشاء طالب جديد ← تصميم البطل (الاسم، اللون، العباءة، الزينة، العيون).
2. قصة البداية مع حكيم الحروف.
3. **خريطة ثلاثية الأبعاد** فيها سبع جزر (الغابة، الصحراء، البحر، الثلج، الحلوى، النجوم، قلعة قوس قزح) وقلعة المملكة. لا يُفتح العالم التالي إلا بعد إكمال حروف العالم السابق وفتح صندوق كنزه (مفتاح 🔑)، مع إمكانية مراجعة العوالم المفتوحة دائماً.
4. **مرحلة الحرف:** الحرف كبيراً مع نطقه، الحرف بالفتحة والضمة والكسرة، صور كلمات تبدأ به مع أسمائها، وأشكاله (منفصل، أول، وسط، آخر) مع كلمة مثال لكل موضع يُبرز فيها الحرف مع الحفاظ على اتصال الحروف، وتنبيه للحروف التي لا تتصل بما بعدها (ا د ذ ر ز و).
5. **خمس ألعاب لكل حرف** (٥ أسئلة لكل لعبة، بصعوبة متدرجة وترتيب عشوائي):
   | اللعبة | الفكرة | التدرج |
   |---|---|---|
   | 👂 استمع واختر | يُنطق الحرف ويختاره الطالب | خياران ← ٣ ← ٤ ← حروف متشابهة ← تمييز الحركة |
   | 🎈 اصطد الحرف | بالونات متحركة، يُنقر الحرف المطلوب ٣ مرات | سرعة أكبر وحروف متشابهة |
   | 🧩 طابق الصورة | سحب الحرف (أو نقره ثم نقر الصورة) إلى الصورة التي تبدأ به | صور بأسمائها ← دون أسماء ← ٤ صور متشابهة |
   | 🔤 أكمل الكلمة | اختيار الحرف الناقص في كلمة مصوّرة | أول الكلمة ← وسطها ← آخرها |
   | ✍️ ارسم الحرف | تتبّع الحرف بالإصبع أو الفأرة من نقطة البداية الخضراء | منفصل ← أول ← وسط ← آخر، مع دليل يخفت تدريجياً |
6. **اختبار إنقاذ المملكة:** ٢٨ سؤالاً (سؤال لكل حرف) بستة أنواع: تمييز الحرف، سماع الصوت، اختيار الصورة، أشكال الحروف، الحركات، الكلمة الناقصة. النتيجة من ١٠٠ مع مستوى الإتقان وتوصيات بالحروف التي تحتاج مراجعة.
7. **شاشة النهاية:** تضيء المملكة وتعود الحروف إلى أماكنها، ويقول حكيم الحروف: «أحسنت يا بطل! لقد أنقذت مملكة الحروف، وأصبحت فارس الحروف العربية!»، ثم **شهادة إنجاز** باسم الطالب قابلة للطباعة أو الحفظ PDF.

## التغذية الراجعة والمكافآت
- لا عقاب على الخطأ: اهتزاز لطيف وعبارة تشجيع، وبعد خطأين يظهر تلميح تلقائي. زر 💡 (أو الضغط على حكيم) يعطي تلميحاً في أي وقت.
- ⭐ نجمة لكل إجابة صحيحة من المحاولة الأولى (٥ لكل لعبة، ٧٠٠ إجمالاً)، و**ثلاث نجوم إتقان** عند إنهاء اللعبة دون خطأ.
- 🔑 مفاتيح العوالم، 🎁 صناديق كنوز فيها زينة جديدة للبطل، ١٢ شارة إنجاز، واحتفالات بصرية وصوتية.

## لوحة المعلم
محمية برمز سري (يُحفظ مُجزّأً SHA-256 مع ملح).
- إضافة الطلبة وتعديلهم وحذفهم (فرادى أو قائمة أسماء).
- متابعة تقدم كل طالب: النجوم، الحروف المكتملة، العوالم، متوسط الإتقان، الاختبار النهائي، وقت اللعب.
- **تقرير الصف:** خريطة حرارية لإتقان كل حرف لكل طالب، ومتوسط الصف، والحروف الأضعف.
- **تقرير فردي:** إتقان الحروف الـ٢٨، الأداء حسب نوع اللعبة، تفاصيل كل لعبة، محاولات الاختبار، وتوصيات.
- **إعادة أنشطة حروف محددة** (يمسح تقدمها ليعيدها الطالب) أو **تكليف بمراجعتها** (تظهر للطالب على الخريطة 📌 وتُزال تلقائياً بعد إعادة ألعابها).
- **تصدير Excel** حقيقي (.xlsx بأربع أوراق من اليمين إلى اليسار) و**PDF** عبر الطباعة.
- نسخة احتياطية JSON واستعادتها.

**حساب الإتقان:** متوسط أفضل نتيجة في الألعاب الخمس للحرف (اللعبة غير الملعوبة = صفر)، ويُدمج معه سؤال الحرف في آخر اختبار نهائي بوزن ٢٠٪. متقن ≥ ٨٠٪، قيد التقدم ٥٠–٧٩٪، يحتاج دعماً < ٥٠٪. لا توجد أي بيانات تجريبية؛ كل ما يظهر نتائج حقيقية للطلبة.

## الصوت
- النطق بالأصوات العربية المدمجة في الجهاز (Web Speech API) مع تفضيل أفضل صوت عربي متاح وسرعة مناسبة للأطفال.
- **بديل عند تعذّر النطق:** يظهر النص مكتوباً في فقاعة حكيم الحروف مع نغمة تنبيه، فتبقى كل الأنشطة قابلة للعب.
- يمكن إضافة **تسجيلات بصوت المعلم** (mp3) في مجلد `audio/` وتسجيلها في `audio/manifest.js`؛ تُستخدم بدلاً من النطق الآلي.
- كتم الصوت، مستوى الصوت، الموسيقى، وسرعة النطق من ⚙️ الإعدادات.
- لتثبيت صوت عربي: Windows ← الإعدادات ← الوقت واللغة ← الكلام؛ Android ← تحويل النص إلى كلام؛ iPhone/iPad ← تسهيلات الاستخدام ← المحتوى المنطوق.

## التخزين والخصوصية
تُحفظ البيانات تلقائياً في متصفح الجهاز (localStorage) وتبقى بعد إغلاق اللعبة، ولا تُرسل إلى أي خادم. تُمسح إذا مُسحت بيانات المتصفح، لذا يُنصح بالنسخ الاحتياطي من لوحة المعلم. البيانات خاصة بالجهاز والمتصفح المستخدَمين.

## بنية الملفات
```
letters/
  index.html        الصفحة الرئيسية (اللعبة + لوحة المعلم عبر #teacher)
  teacher.html      رابط مباشر للوحة المعلم
  css/app.css       التصميم الكرتوني المتجاوب والطباعة
  js/data.js        المحتوى اللغوي: الحروف، الأشكال، الحركات، الكلمات المصوّرة، أدوات الاتصال
  js/store.js       التخزين، الإتقان، الشارات، الكنوز، الرمز السري
  js/audio.js       النطق العربي والبديل، المؤثرات والموسيقى
  js/art.js         البطل وحكيم الحروف (SVG) والاحتفالات
  js/map3d.js       الخريطة ثلاثية الأبعاد (مع خريطة بديلة إن تعذّر WebGL)
  js/games.js       الألعاب الخمس وبنك أسئلة الاختبار النهائي
  js/app.js         الشاشات والتنقل
  js/teacher.js     لوحة المعلم والتقارير
  js/export.js      مولّد ملفات Excel
  audio/manifest.js تسجيلات صوتية اختيارية
```
لتعديل الكلمات أو الصور عدّل مصفوفة `RAW` في `js/data.js`.
